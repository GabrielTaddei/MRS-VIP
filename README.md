# MRS VIP — Além do Palco (Case Prêmio Aberje 2026)

Apresentação web interativa (GitHub Pages).

## Publicar
1. Suba `index.html` e a pasta `assets/` na raiz do repositório (ou em uma subpasta).
2. Settings → Pages → Deploy from branch → `main` / root.

## Navegação
- ← → / espaço / clique / swipe: avançar e voltar
- F: tela cheia · M: índice · P: apresentação automática (7s por slide)
- Link direto para um slide: `index.html#12`
